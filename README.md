# parqueTexcal
Última versión del sistema del parque 

Este es un proyecto de desarrollo web sobre la difusión del parque estatal “El Texcal” por medio de publicaciones e información actual que ayude a los visitantes a conocer los espacios y servicios con los que éste cuenta, además de llevar a cabo una correcta organización del personal para efectuar los distintos cambios y mantenimientos por el que éste atraviesa.


OBJETIVO GENERAL

- Desarrollar un sistema web que permita la difusión de la publicidad así como la administración de mantenimientos, locales, tarifas y empleados del parque estatal “El Texcal”.

OBJETIVOS ESPECÍFICOS

- Licitar los requisitos funcionales para identificar las funciones principales que requiere el cliente.
- Analizar los requisitos funcionales con el fin de evitar malas interpretaciones acerca del funcionamiento.
- Elaborar una planeación de la implementación del sistema para llevar a cabo una buena organización.
- Diseñar los requisitos funcionales para permitir una mejor visualización de las funciones del sistema.
- Elaborar los diseños de interfaz para identificar los componentes necesarios y que estos sean agradables para la vista del usuario.
- Diseñar el modelo relacional de la base de datos a partir del cual se podrá realizar el modelo físico.
- Seleccionar las tecnologías adecuadas con el fin de facilitar la implementación del sistema.
- Implementar los módulos del sistema para integrar los requisitos licitados.
- Probar cada uno de los requisitos del sistema web para detectar y corregir errores.

RESTRICCIONES DE DISEÑO
- RD.1. El sistema será web.
- RD.2. El sistema contará con cinco tipos de usuarios: administrador, visitante, guía, vendedor y mantenimiento.
- RD.3. El navegador utilizado para el sistema será Chrome, Opera, Brave.
- RD.4. Se utilizará el framework de Bootstrap para el lado del cliente.

REQUISITOS FUNCIONALES
Los requisitos funcionales reflejan las funciones que debe prestar el sistema. Se clasifican en las siguientes subsecciones:

 - Requisitos funcionales nominales
      1. Registro de usuarios tipo visitante.
      2. Inicio de sesión de usuarios.
      3. Recuperación de usuario y contraseña.
      4. Gestión de empleados.
      5. Publicación de imágenes y videos.
      6. Gestión de comentarios.
      7. Gestión de boletos.
      8. Gestión del catálogo de productos.
      9. Control de Mantenimiento.
      10. Control de visitas guiadas.
      11. Chat.
      12. Archivero
      13. Gestión de eventos
      14. Reportes
      15. Respaldo y recuperación de la base de datos
      16. Gestión de locales.
      
- Requisitos funcionales no nominales
